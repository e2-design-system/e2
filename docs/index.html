E2 Design System defines three related visual asset systems: interface icons, GIS marker symbols, and illustrative symbols. Each system has its own constraints, but all share the same visual DNA: geometric clarity, restrained complexity, reliable SVG output, and technical precision.

Icon System 24 px UI icons, stroke rules, primitive limits, and export constraints. GIS Marker System POI markers, anchors, containers, map contrast, and scale behavior. Symbol System 200 px illustrative pictograms for larger technical communication. QA Production checklist for design, export, naming, and implementation.
