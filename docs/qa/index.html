QA Checklist

Icons

  • ViewBox is 0 0 24 24.
  • Stroke follows the size rule.
  • Cap and join are round.
  • Icon is recognizable at 16 px.
  • No more than three primary primitives.
  • No unnecessary fills.
  • No hidden shapes or accidental transforms.

GIS markers

  • Anchor assumption is documented.
  • Marker is legible on light, dark, and satellite backgrounds.
  • Glyph is not too detailed.
  • Container and glyph contrast is sufficient.
  • Selected and default states are visually distinct.

Illustrative symbols

  • ViewBox is 0 0 200 200.
  • Stroke is 4 px at base size.
  • Symbol is readable at 100 px.
  • Visual center is optically balanced.
  • Fills are intentional and subtle.
  • No essential meaning is conveyed only through tiny details.

Release QA

  • File names are semantic.
  • Metadata exists.
  • SVGs open correctly in browser.
  • SVGs are editable in Illustrator or Figma.
  • Assets are included in the correct catalog.
