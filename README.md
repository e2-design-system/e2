## Overview

The **e² Design System** is a rule-based visual language for representing:

- Environmental systems  
- Marine and geospatial data  
- Engineering concepts  

It combines:
- **Material-inspired geometry**
- **Cartographic symbology principles**
- **Engineering-level semantic consistency**

---

## Features

- Minimal, scalable symbol system (24px, 2px stroke)
- Domain-specific semantics (marine, hydrography, engineering)
- Pattern system for continuous data representation
- GIS-ready structure (QGIS / ArcGIS compatible)
- Consistent abstraction and visual grammar

## What's Included

### Symbols
- Marine vessels
- Oceanographic elements
- Engineering components

### Patterns
- Directional flow patterns
- Density / intensity patterns
- Contour and hatch systems

### Formats
- SVG (primary)
- QGIS styles (.qml)
- ArcGIS styles (.stylx)
- Figma-ready assets

---

## Design Principles

- **≤ 3 semantic primitives per symbol**
- **≤ 5 paths per icon**
- One concept per symbol
- No contextual elements (e.g., waves, ground)
- Built for clarity at small sizes (16–24px)
